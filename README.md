# infodetectiv
 InfoDetectiv – Detectarea informațiilor false

InfoDetectiv este o aplicație educativă care îi ajută pe elevi să diferențieze informațiile adevărate de cele false.

Pentru cine este și cum se joacă?

Aplicația este destinată elevilor de clasa a XI-a. Aceștia folosesc aplicația pentru a exersa identificarea informațiilor adevărate și false, urmând activitățile disponibile.
